# Frontend React

Interface ecommerce branchée sur le backend Spring Boot et le moteur FastAPI.

## Lancer le projet

```powershell
npm install
npm run dev
```

Par défaut, l'application parle au backend sur `http://localhost:8080`.
Si besoin, ajoute un fichier `.env` avec :

```bash
VITE_API_BASE_URL=http://localhost:8080
```
